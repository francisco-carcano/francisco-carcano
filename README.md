#### What I've done in industry

**Zitro: a shared definition of success for 200+ games**
Game performance was judged with subjective labels. On my own initiative, I aligned the heads of maths, product management and game design on what "success" means, built an index from revenue, engagement and machine-utilisation data, and validated it case by case with them. It became the company-wide benchmark that product and game design teams use to pick reference games for new products.
